# スポットイラストを描く

単元の物語の場面に、見出しの横の小さな絵を足す。絵柄の決まりは`docs/visual-guidelines.md` 6章が正本で、背景はADR 0004。
この手順の目的は、誰がいつ描いても既存の絵と見分けがつかないこと。新しい表現を試す場ではない。

引数: `/spot-illustration <単元ID>`(例: `merchandise/three-account-method`)。単元が無ければ、どの単元に入れるかを先に聞く。

## 1. 読む(描く前に必ず)

1. `docs/visual-guidelines.md` 6章。枠、線、塗り、置き方の決まり。
2. `src/components/illustrations/spot-illustration.tsx`の全部。既存の絵が手本で、座標の取り方、要素の数、塗りの配分をここから写す。
3. 対象の単元(`content/topics/<単元ID>.md`)。場面が変わるステップを拾う。

## 2. 何を描くか決める

- 置くのは場面が変わるステップだけ。1単元で多くても6点。ふりかえりと、図解が主役のステップには置かない。
- その場面を代表する物を1つ選ぶ(建物、道具、お金、書類)。人物、手、表情は描かない。
- 既存の絵で足りるなら新しく描かない。`src/lib/illustrations.ts`の一覧を先に見る。同じ単元で同じ絵は2回使わない。
- 名前は物の名前を英語のkebab-caseで付ける(`delivery-van`)。場面の名前(`step3`、`buy-machine`)にしない。

描く前に、ステップと絵の対応を表にしてユーザーに見せる。新しく描く点数が3点を超えるときは、了承を得てから描く。

## 3. 描く

`spot-illustration.tsx`の`DRAWINGS`に足し、`src/lib/illustrations.ts`の`ILLUSTRATION_NAMES`に名前を、`ILLUSTRATION_LABELS`に一覧へ出す日本語の名前を足す。

形の作り方(既存の6点に共通するやり方)。

- 正面か真横から見た形にする。斜めの見下ろし、遠近、奥行きの線は使わない。重なりは、同じ形を少しずらして置くことで表す(札束、硬貨)。
- まず大きな面を2〜3個置く(本体、屋根、台)。そのうち1〜2個を主色で塗り、残りは紙にする。
- 差し色は小さな面に2〜4か所(ボタン、硬貨、日よけ、札)。淡色は窓や奥の面に使う。墨の塗りは小さな点か、濃さが要る1か所だけ。
- 角は`rx`で丸める(大きな面は4〜7、小さな面は1〜2)。円と楕円を積極的に使う。
- 細部は細い線(1.8)で3〜4本まで。棒状の物(鍵の軸、取っ手)だけ太い線(4か5.5)を使う。
- 地面の線は建物にだけ引く(`M8 104H114`のような1本)。物は浮かせたまま置く。
- 絵は枠の8〜112に収め、中心を60,60の近くに置く。後ろの物から順に書く(SVGは後に書いた物が上になる)。
- 座標は0.5刻みまで。1点は25要素まで。

使えるクラスと属性はこれだけ。

| 用途 | 書き方 |
|---|---|
| 紙 | `className="fill-card"` |
| 主色 | `className="fill-primary"` |
| 差し色 | `className="fill-brand-accent"` |
| 淡色 | `className={TINT}` |
| 墨 | `className="fill-foreground"` |
| 細い線 | `strokeWidth={THIN}` |
| 太い線 | `strokeWidth={4}` / `strokeWidth={5.5}` |
| 主色の面の上の白い線 | `className="stroke-card"` |

色の値、`style`、`opacity`、`<text>`、`<g>`、グラデーション、`transform`は使わない。

## 4. 確かめる

1. `pnpm vitest run src/components/illustrations`。決まりのうち機械で分かるものを検査する。
2. 開発サーバー(`make dev`)を起動し、`make illustrations`。`logs/illustrations/`に、4テーマ × ライト・ダークの8枚が出る。
3. `town-shop-light.png`と`town-shop-dark.png`を必ず開いて見る。ほかのテーマは、色が沈んで形が読めなくなっていないかを1枚ずつ見る。

見るところ。1つでも当てはまれば描き直す。

- 名前を見ずに何の絵か分かるか。見本は160pxなので、76pxで分かるかは組み込んだあと単元の画面で見る。
- 既存の絵と並べて、線の密度、塗りの量、大きさ(枠に占める割合)がそろっているか。新しい絵だけ細かい、または大きい、ということがないか。
- 線が塗りからはみ出したり、重なりの順番が逆になったりしていないか。
- 主色の面が3つ以上になっていないか。差し色が大きな面を占めていないか。

描き直しは3回まで。それでもそろわなければ、物の選び方を変える(もっと単純な形の物にする)。

## 5. 単元に組み込む

ステップの`## 見出し`の直後に置く。

````markdown
## コーヒーマシンを買う
```illustration
coffee-machine
```
````

`make content`で検査し、単元の画面(`/units/<単元ID>`)でステップを送って、見出しの横に出ることを確かめる。コンテンツを変えたので`make e2e`を回す。

## 6. 報告

追加した絵の名前、置いたステップ、`logs/illustrations/town-shop-light.png`のパスを伝える。見ていないテーマや幅があれば、そう書く。
