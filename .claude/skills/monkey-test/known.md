# 既知の挙動(起票しない)

再発見してもIssueにしない。直すべきと判断したものは、ここから消して起票する。

- 初回のページ読み込みが遅い(5〜30秒)。`pnpm dev`がページごとにコンパイルするため。同じページの2回目以降が遅ければ異常。
- 匿名ユーザーは最初の回答(記帳・確認)のときに作られる。閲覧だけでは`auth.users`に増えない。
- 初回バナー「初めてですか?」は通常の単元を初めて開いたときだけ出る。チュートリアルの単元では出ない。
- 「← 前へ」は入力中の仕訳があると`window.confirm`で確認する(Playwrightは既定でdismissするので、戻らないのは正常)。
- 「次へ →」は課題が未達のあいだ`aria-disabled`で、押しても何も起きない。
- `[[id]]`の用語リンクは表の中では`[[id]]`だけ(別名表示が無い)。
- 帳簿をさかのぼる(range)は2件以上記帳してから出る。
- 最後のステップの「自由に試す」で記帳した仕訳は保存されず、reloadで消える(Issue #160)。貸借がそろうまで「記帳する」は押せない。
- 途中まで進めた単元をタブを開き直して開くと、ステップ1に「続きから」が出る(自動では再開しない)。案内は最初のステップにいる間だけ出る。
- 同じ誤答を繰り返しても「答えを見る」は出ない(答えを変えて2回間違えたときに出る)。
- postは貸借の合計が不一致でも「記帳する」を押せる(採点して、そろえるよう案内する。Issue #199)。
- `view: none`の単元(覚え書きの時代)には仕訳帳も結果の表も無い。`view: ledger`の単元には貸借対照表と損益計算書が無く、試算と元帳が出る。
- 見た目のテーマと明るさはlocalStorageだけに保存する。Cookieを消しても残り、別のブラウザには引き継がれない。
- `scenario.opening`に評価勘定(減価償却累計額など)の期首残高を持てない(docs/content-model.mdに記載の既知の制限)。
- 期を締める(決算)はまだ無い(M2)。
- Playwrightのscreenshot中に1回だけ出るhydration警告(キャレット非表示によるもの)。操作無しのreloadで再発しなければ無視する。
