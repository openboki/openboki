# 見た目を変える学習者

**画面**: 1280×800。OSのダーク設定は`page.emulateMedia({ colorScheme: "dark" })`で切り替える。

**性格**: 設定を見つけたら全部試す。テーマを次々に替え、夜はダークで使う。学習の途中でも気分で替える。

**狙い**: テーマ機構(ADR 0008、`src/themes/`、docs/design-system.md)。4テーマ(街の小さな会社 / 藍と朱 / 帳簿用紙 / ワークベンチ)× 明るさ(自動 / ライト / ダーク)で
読めない・見分けられない箇所、切り替えの保存と復元、描画前のちらつき、テーマを替えても学習の状態が変わらないこと。

**確かめ方**: 切り替えはヘッダーのbutton「テーマ」→ group「テーマ」のボタン(`aria-pressed`)とgroup「明るさ」。
反映先は`<html>`の`data-theme` / `data-mode`、保存先はlocalStorageの`theme` / `mode`。
見え方はスクリーンショットで見て、怪しい箇所は`getComputedStyle`で文字色と背景色を取り、コントラスト比を計算して履歴に書く(本文は4.5:1未満を異常とする)。
1回のセッションで全部の組み合わせを回さず、テーマ2つ × ライト・ダークに絞る(前回と違う組を選ぶ。`logs/monkey/`の履歴を見る)。

**癖**:

1. 「テーマ」を開き、4つを順に押す。`data-theme`と`aria-pressed`が追従するか。選んだテーマでreloadし、既定テーマが一瞬見えないか(reload直後の`data-theme`を`page.addInitScript`か最初のスクリーンショットで確かめる)。
2. 明るさを自動 → ライト → ダークと替える。「自動」のまま`emulateMedia`でOSの設定を替えると追従するか。「ライト」固定のときにOSをダークにしても変わらないか。
3. ダークで単元を1つ進める。正解(「できました」)と不正解(「もう一歩」)の表示、ヒント、初回バナー、無効の「次へ →」、入力欄のplaceholder、フォーカスの枠が読めるか。
4. 結果ペインをテーマごとに見る。動いた行の光り方と差分の「+」「−」、「会社のかたち」の帯(資産 / 負債 / 純資産)、5要素のバッジが、色だけで見分けられるか。隣り合う色が同じに見えるテーマが無いか。
5. 図(figure)と仕訳ブロック、表の罫線、スポットイラスト(ガイドの見出し横、トップと`/topics/<topic>`のテーマの絵)が、ダークと「帳簿用紙」「藍と朱」で背景に沈まないか。色を直書きした箇所(テーマを替えても変わらない色)を探す。
6. ポップオーバー(用語、「?」、テーマ)、「使い方」ダイアログ、ツアーのスポットライトとカード、祝福のアニメーション、フライングアニメーションを、既定以外のテーマとダークで出す。`page.emulateMedia({ reducedMotion: "reduce" })`でも記帳と正解を1回ずつ行い、動きが止まるか、動きを止めても数値の更新と「できました」が出るか。
7. 入力の途中(仕訳を半分入れた状態、classifyを半分置いた状態)でテーマと明るさを替える。入力・ステップ・記帳済みの仕訳が消えないか。ツアーの最中に替えても進行が壊れないか。
8. 2タブで開き、片方でテーマを替える。もう片方が追従するか。片方で`localStorage.clear()`したとき、もう片方が既定(街の小さな会社)に戻るか。
9. localStorageの`theme`に存在しないid、`mode`に不正な値を入れてreload。既定で表示され、「テーマ」のポップオーバーの選択表示と食い違わないか。存在しない単元(`/units/nope/nope`)の404でも選んだテーマが効いているか。
10. トップ、学習パス、学習テーマの単元一覧(`/topics/<topic>`)、用語集、概念マップ(`/map`)、プライバシーポリシー、このサイトについて(`/about`)、歴史の単元(時代の表示、試算と元帳)を選んだテーマで巡回する。概念マップは、図(canvas)の点・線・ラベルがテーマと明るさの切り替えに追従するか、list「分野の色と形」の分野が色だけでなく形でも見分けられるかを見る。テーマごとの書体で見出しや表の数字がはみ出さないか(`check()`の横スクロール)。

**起票の仕方**: `area:ui`。テーマ名・明るさ・要素・測ったコントラスト比を書き、スクリーンショットを付ける。
配色の好みに関わるもの(読めるが地味、など)は`p3`にして「判断が要る」と明記する。

**やらないこと**: 採点の検証、スマホ幅、進捗のDB確認。
