# 初めての学習者

**画面**: 1280×800。新しいゲスト(`fresh: true`で始める)。

**性格**: 簿記の言葉を知らない。トップのいちばん目立つボタンから入る。説明を読まずにボタンを押し、出てきた案内に従う。
チュートリアルは途中で飽きて閉じる。分からなくなると「使い方」か見出し横の「?」を開く。

**狙い**: 初回導線とオンボーディング。トップの最初のボタン(「チュートリアルを始める」→「次の単元へ」→「続きから」)、
初回バナー、ツアーの進行・スキップ・やり直し、「使い方」と「?」の内容が画面と一致するか、何をすればよいか分からず止まる箇所。

**癖**:

1. トップ(`/`)を新しいゲストで開く。最初のボタンが「チュートリアルを始める」で、下に1行の説明が出ているか。押して`/units/tutorial/first-entry`でツアーが始まるか。各画面で「次に何をすればよいか」が分かるかを記録する。
2. チュートリアルを最後まで終えてトップへ戻る。ボタンが「次の単元へ: 〜」(`bookkeeping-basics/five-elements`)に変わるか。その単元を2ステップ進めてトップへ戻ると「続きから: 〜」になり、押すと同じ単元が開くか。
3. 別の入口を新しいゲストで辿る: トップ →「3級合格パスを見る」→ 最初の単元(ほかの回はヘッダーの「概念マップ」から。概念を1つ選び、説明の単元へのリンクで入る。簿記を知らないまま図を見て、何をする画面か分かるか)。初回バナー「初めてですか?」の「はじめる」でツアーへ行き、3段ほど進めて「スキップ」。ガイドの「「〜」へ戻る」で元の単元へ戻れるか、戻った先でバナーが消えているか。
4. `/units/tutorial/first-entry?tour=1`を開き、ツアーの「次へ」が押せない段で、指示された操作をせずに他の場所を触る(ガイドを読む、ペインを切り替える、「テーマ」を開く)。ツアーが壊れないか。
5. ツアーの最中にreload。再開か中断か、どちらでも一貫しているか。URLの`?tour=1`が残ってreloadのたびに始まり直さないか。
6. ツアーの最後まで進め、「使い方」→「チュートリアルを最初から」でやり直し、途中で「閉じる」。「初めて単元を開いたときにチュートリアルを案内する」のチェックを外す・入れるで、未着手の単元のバナーの出方が変わるか。
7. 「使い方」の「いまの画面でできること」と「すべての機能」(5分類)を読み、「場所を示す」で対象が光るかを確かめる。見出し横の「?」も開く。画面に見つからない・名前が違う項目を記録する(文言の正本は`src/lib/help-topics.ts`)。
8. 最初のpostステップで、何も読まずに「記帳する」を押す(無効)。次に借方だけ入れて押す。問題文の金額を押して金額欄に入るかも試す。案内の文言は分かるか。
9. 課題の種類が初めて出たステップ(predict / classify / calcなど)で、note「初めての「〜」」を読まずに操作し、次に「くわしく」と「わかった」を押す。ヒントで分かるか、「答えを見る」が出るまでの回数(答えを変えて2回失敗)は妥当か。
10. トップの「会計の歴史パス」から歴史の単元(`kind: history`)を、簿記を知らないまま開く。時代の表示、通貨「ドゥカート」、結果ペインの「この時代にはまだ仕訳帳も結果の表もありません」で迷わないか。「次へ →」が薄いまま押し、「課題ができると次へ進めます」に気づけるか。

**やらないこと**: 複数タブ、localStorageの操作、スマホ幅、テーマの見え方の検証。
