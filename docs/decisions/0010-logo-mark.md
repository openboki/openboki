# 0010. ロゴマークは「開いた輪と点」とし、SVG 1枚を正本にする

日付: 2026-11-15
状態: 採用(ユーザー決定2026-11-15。実装2026-11-15)

## 背景
faviconがcreate-next-appの初期ファイルのままで、ロゴもなかった。ヘッダーは「Open簿記」の文字だけだった。
faviconが最初のロゴマークになるので、図案の意図と作り方を合わせて決めた。名前とロゴは商標として扱う(ADR 0007)。

## 決定
- **図案は「開いた輪と点」。** 角丸の緑のタイルに、右上に切れ目のある白い輪と、切れ目の外に置いたはちみつ色の点を描く。
- **輪は「Open」のO、切れ目は誰でも入れる入口。** ログインも費用も要らず、誰でも学べる開放性を表す。切れ目は約40°に抑え、CではなくOと読める幅にした。
- **点は足される知識と、入ってくる人。** コンテンツをコミュニティで共有して育てることを表す。色は`--brand-accent`で、design-system.mdが「ロゴの印」に充てている差し色と一致させた。
- **点は輪の外に置く。** 簿記から会計・税務へ範囲を広げていく拡張性を表す。輪の中に収めると、閉じた範囲の中の一部に見える。
- **簿記の記号は使わない。** T字勘定や「簿」の字は、対象を簿記に閉じて見せる。「簿」は16pxで潰れる。
- **正本は`src/app/icon.svg`の1枚。** 手書きのSVGで、色は既定テーマ(town-shop)のライトの値を直接書く(地`#1e6b62`、輪`#ffffff`、点`#e0a23a`)。テーマやライト・ダークの切り替えでは変えない。
- **`favicon.ico`(16px・32px)と`apple-icon.png`(180px)は`make icons`で書き出してコミットする。** 手で編集しない。配置はNext.jsのファイル規約に任せ、`metadata.icons`は書かない。

## 影響
- `sharp`をdevDependencyに足し、`scripts/icons.mjs`と`make icons`が入る。
- `manifest`と192px・512pxのアイコンは、Androidのホーム画面追加に対応するときに足す。
- ヘッダーやOGP画像にロゴを使うときは、`icon.svg`と同じ形と色を使う。
- 類似ロゴの調査はしていない。「開いた輪」はオープン系のロゴに多い形なので、商標として使い始める前に確認する。

## 検討した別案
- **向き合う二つの弧**: 教える側と学ぶ側、左右の釣り合いを表せて、大きく見せたときの独自性は高い。16pxでははちみつ色の弧が緑の地に沈み、白い弧だけが「C」に見えた。不採用。
- **一角が開いた枠**: 拡張性は最も直接に表せるが、外部リンクのアイコンに近い。不採用。
- **足されるブロック**: 育てることは伝わるが、4分割の四角は既存のアイコンと紛れやすく、16pxでは1マスが5px程度になる。不採用。
- **画像生成AIで作る**: 出力がラスターで小さいサイズで潰れ、修正を差分で追えず、権利の所在と既存ロゴとの類似を確かめにくい。不採用。
- **`icon.tsx`と`ImageResponse`で生成する**: 画像ファイルを持たずに済むが、`favicon.ico`は生成できず、静的なアイコンには大げさ。不採用。
