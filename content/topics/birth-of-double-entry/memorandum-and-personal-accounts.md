## リアルト橋のそばで
1385年の春、あなたはヴェネツィアの商人バルトロメオの店で見習いになりました。店は胡椒と布とワインを、船で運んで売り買いしています。帳簿は1冊だけ。起きたことを起きた順に、文章で書いていく[[memorandum_book|覚え書き]]です。
前の単元で使った左右2列の仕訳帳も、結果の表も、ここにはありません。それらはこの時代の商人たちが、これから百年あまりかけてたどり着くものです。この単元では、まだ複式簿記の無い店で帳簿を預かり、何に困り、どう工夫したかを追体験します。

## ジョヴァンニにいくら貸している?
朝いちばんにバルトロメオが聞きます。「ジョヴァンニは、いまいくら貸しがある?」 覚え書きの3月分はこうです。

| 3月 | 覚え書き |
|---|---|
| 2日 | ジョヴァンニに胡椒20袋を売った。代金60ドゥカートは後で受け取る |
| 3日 | ニッコロから布10反を買った。代金40ドゥカートは後で払う |
| 5日 | ジョヴァンニから胡椒の代金のうち30ドゥカートを受け取った |
| 7日 | マッテオに布4反を売った。代金20ドゥカートは後で受け取る |
| 9日 | ジョヴァンニにワイン5樽を売った。代金25ドゥカートは後で受け取る |
| 11日 | ニッコロに布の代金のうち20ドゥカートを払った |
| 12日 | 店の家賃8ドゥカートを払った |
| 14日 | ジョヴァンニから15ドゥカートを受け取った |
| 16日 | マッテオから20ドゥカートを受け取った |
| 18日 | ジョヴァンニから布2反を買った。代金10ドゥカートは後で払う |
| 20日 | ジョヴァンニに胡椒10袋を売った。代金30ドゥカートは後で受け取る |
| 22日 | ジョヴァンニに布の代金10ドゥカートを払った |

1つの出来事を1か所に1回だけ書く、この記録の仕方を[[single_entry|単式の記録]]と呼びます。書くのは簡単です。その代わり、残高を知りたくなるたびに、関係する行を拾い集めて足し引きすることになります。ジョヴァンニの行を拾って、数えてみましょう。

```task
type: calc
question: 3月22日の時点で、ジョヴァンニはバルトロメオの店にいくら支払いが残っているか(ドゥカート)
answer: 70
wrong_patterns:
  - match: 115
    misconception: claim_ignores_receipts
    feedback: 売った60、25、30を足しただけになっています。3月5日と14日に受け取った分は、もう貸しではありません。
  - match: 80
    misconception: credit_purchase_as_claim
    feedback: 3月18日の布は、こちらがジョヴァンニから買ったものです。これは貸しではなく、こちらが払う側でした(22日に払っています)。
  - match: 60
    feedback: 3月2日のほかに、9日と20日にも売っています。受け取った分も引きましょう。
hint: ジョヴァンニの行だけを拾い、売った額を足し、受け取った額を引きます。こちらが買って払った分は、貸しとは別です。
success: 70ドゥカートです。答えは出ましたが、12行から1人の行を7つ拾って足し引きしました。相手が30人いたら、聞かれるたびにこれをやることになります。
```

## 人ごとにページを分ける
商人たちは工夫しました。相手ごとにページを作り、覚え書きからその相手の行を写すのです。ページの左には「彼がこちらに負う」ことを、右には「こちらが彼に負う」ことを書きます。これが[[personal_account|人名勘定]]です。
ジョヴァンニのページに、3月2日と5日の2行を写すとこうなります。

| 彼がこちらに負う | ドゥカート | こちらが彼に負う | ドゥカート |
|---|---|---|---|
| 3月2日 胡椒20袋を売った | 60 | 3月5日 受け取った | 30 |

売ったので「彼がこちらに負う」が増えて左、受け取ったので彼の負いが減って右です。受け取ったお金が店に入ってきても、ジョヴァンニのページでは右に書くことに注意してください。このページの主役はお金ではなく、ジョヴァンニとの貸し借りです。
左右の見出しは、イタリアの商人の言葉で「彼は与えるべし(dare)」「彼は受け取るべし(avere)」でした。英語ではdebitとcreditになり、日本では明治の初めに『帳合之法』で西洋の簿記が紹介されたときに、借方・貸方と訳されました。前の単元で「難しそうな名前だが左と右の呼び名にすぎない」と言った[[debit_credit|借方と貸方]]は、もとは人名勘定の「相手が借りている側」「相手が貸している側」の名前だったのです。増える・減るの意味は、最初から入っていません。

## 残りの行を写す
ジョヴァンニの残りの5行を、ページの左右に振り分けてみましょう。迷ったら「ジョヴァンニがこちらに負う方向か、こちらがジョヴァンニに負う方向か」と考えます。

```task
type: classify
labels:
  left: 左(彼がこちらに負う)
  right: 右(こちらが彼に負う)
items:
  - { id: mar9_wine, label: 3月9日 ワイン5樽を売った。25ドゥカートは後で受け取る, answer: left }
  - { id: mar14_receipt, label: 3月14日 代金15ドゥカートを受け取った, answer: right }
  - { id: mar18_cloth, label: 3月18日 布2反を買った。10ドゥカートは後で払う, answer: right }
  - { id: mar20_pepper, label: 3月20日 胡椒10袋を売った。30ドゥカートは後で受け取る, answer: left }
  - { id: mar22_payment, label: 3月22日 布の代金10ドゥカートを払った, answer: left }
misconceptions:
  mar14_receipt: { left: personal_account_by_cash_direction }
  mar22_payment: { right: personal_account_by_cash_direction }
  mar18_cloth: { left: credit_purchase_as_claim }
hint: お金の出入りではなく、貸し借りの向きで決めます。彼に売った・彼に払ったは左、彼から受け取った・彼から買ったは右です。
success: 全部写せました。3月22日に払った10ドゥカートが左にあるのは、こちらが彼に負っていた布の代金を返して、負いが消えたからです。
```

## ページを読む
写し終えたジョヴァンニのページです。

| 彼がこちらに負う | ドゥカート | こちらが彼に負う | ドゥカート |
|---|---|---|---|
| 3月2日 胡椒20袋を売った | 60 | 3月5日 受け取った | 30 |
| 3月9日 ワイン5樽を売った | 25 | 3月14日 受け取った | 15 |
| 3月20日 胡椒10袋を売った | 30 | 3月18日 布2反を買った | 10 |
| 3月22日 布の代金を払った | 10 | | |
| 合計 | 125 | 合計 | 55 |

さっきは12行から拾って数えました。今度はこのページを読むだけで答えが出るはずです。バルトロメオの朝の質問に、もう一度答えてみましょう。

```task
type: calc
question: このページから、ジョヴァンニの支払いの残りはいくらか(ドゥカート)
answer: 70
wrong_patterns:
  - match: 125
    misconception: balance_reads_one_side
    feedback: 左の合計だけを答えています。右にある、受け取った分とこちらが買った分を引きましょう。
  - match: 55
    misconception: balance_reads_one_side
    feedback: 右の合計だけを答えています。残高は左の合計と右の合計の差です。
hint: 左の合計から右の合計を引きます。差が左に残れば、その分を彼がこちらに負っています。
success: 125から55を引いて70ドゥカート。最初に数えた答えと同じです。「拾って数える」が「ページを読む」に変わりました。相手が30人いても、30ページをめくるだけです。
```

## まだ無いもの
人名勘定で、相手のことはいつでも読めるようになりました。それでもバルトロメオの質問には、まだ答えられないものがあります。
「胡椒の商いで、結局いくらもうかった?」「いま店の財産は、全部でいくらある?」 覚え書きにも人名勘定にも、この答えはどこにも書いてありません。
もう1つ、気づきにくい弱点があります。覚え書きからページに写すとき、1行写し忘れたらどうなるでしょう。ジョヴァンニのページは、間違ったまま何も教えてくれません。この2つの不便が、次の単元で複式の発見につながります。

## ふりかえり
覚え書きは[[transaction|取引]]を起きた順に1回だけ書く帳簿で、残高は数えないと分かりませんでした。人名勘定は相手ごとのページに左右で書き、残高を読めるようにしました。左右の見出し「彼がこちらに負う」「こちらが彼に負う」が、借方・貸方という名前の由来です。
いまの簿記では、相手ごとのページの代わりに「後で受け取る権利」「後で払う義務」という性質でまとめた[[account_title|勘定科目]]を使います。あとの単元「掛けで売る、掛けで買う」で出てくるのは、この人名勘定の子孫です。
次の単元では、胡椒の航海1回ごとのもうけを知るために、商人たちが同じ出来事を2か所に書き始めます。
